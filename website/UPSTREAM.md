# Awesome Copilot website baseline

Basic Plugin follows the **structure and interaction model** of the Awesome Copilot website while keeping its own catalog, identity, and build pipeline.

## Reviewed baseline

- Repository: `github/awesome-copilot`
- Commit: `6c4d33b9cfca967a28bb2962ef4d55e4a384c88c`
- Reviewed: 2026-09-26
- Architecture: Astro 7 + React 19 + Primer Brand

The prior reviewed pin (`3a19ac80c2c21f4088417c121cff0d06eadfbee8`) predates a large website architecture rewrite. The sync classifier correctly treats that transition as an architecture migration rather than a routine pin update.

## Structural mapping

| Awesome Copilot source | Basic Plugin adaptation |
| --- | --- |
| `BaseLayout.astro` | document shell, theme bootstrap, metadata, and skip-link behavior |
| `PageShell.tsx` / `TopNav.tsx` | responsive top navigation and page chrome |
| `HomePage.tsx` | hero, resource cards, and closing CTA composition |
| `styles.module.css` | framed gridline layout, responsive card grid, subtle surfaces, focus states |
| `site-data.ts` | local marketplace/index + local plugin capability counts |

## Deliberate differences

Basic Plugin does **not** copy or publish Awesome Copilot's agents, skills, prompts, instructions, plugins, extensions, learning content, contributor data, analytics, or branded image assets.

The local site is generated by the existing dependency-free Node build. This keeps the experiment small while preserving the current upstream information architecture and visual structure. If upstream makes another architecture-level change, the classifier stops the pin and requires another explicit migration.

The machine-readable reviewed state is in [upstream-baseline.json](upstream-baseline.json).
